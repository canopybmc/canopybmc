# Release Notes

This is `rc2` of the Canopy BMC release **2026.06**. Features from 2026.06-rc1
are not mentioned in this release notes.

> [!NOTE]
> This release introduces breaking changes for HPE Proliant Gen11 platforms
> Users of previous versions (eg. _2026.04_) need to do a full update by using (`static.mtd.all.tar`)
>
> For users that want to use the BIOS (Next) boot order feature may have to load
> the BIOS defaults once to synchronise the BIOS variables correctly.

## Features
- OpenBMC
    - OpenBMC bumped to `ec01d283ba` - 2026-07-20 ([#237](https://github.com/canopybmc/canopybmc/pull/237))
- HPE ProLiant Gen11
    - NVRAM / BIOS settings reset support ([#239](https://github.com/canopybmc/canopybmc/pull/239))
    - NVMe drive inventory via UBM support ([#218](https://github.com/canopybmc/canopybmc/pull/218))

## Bugfixes
- HPE ProLiant Gen11
    - PlatDef multi-bundles are now being parsed correctly ([#248](https://github.com/canopybmc/canopybmc/pull/248))
    - Syntax fix for the BIOS Update PLDM script ([#247](https://github.com/canopybmc/canopybmc/pull/247))
